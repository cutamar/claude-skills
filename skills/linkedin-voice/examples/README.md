# Examples of my writing

Put 5–10 real posts and comments here, one per file. These matter more than any rule in `voice.md`.

- Name files `post-YYYY-MM-topic.md` or `comment-YYYY-MM-topic.md`.
- Paste the text exactly as published. For a comment, add one line at the top saying what the post was about.
- Optional: a line like `Worked well: 40 comments, 12 saves` helps pick the best patterns.
