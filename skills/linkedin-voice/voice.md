# My LinkedIn voice

Shared by `linkedin-comment`, `linkedin-reflection` and `linkedin-showcase`. Read this file and every
file in `examples/` before drafting. Rules here beat generic LinkedIn habits.

## How I write

- Plain, direct sentences. Write the way I'd explain it to a colleague at their desk.
- First person, concrete. "I tried X and Y happened", not "Many professionals find...".
- Say what I'm unsure about. Uncertainty is often the most interesting line.
- Short paragraphs, one job each. Lists only for steps or parallel items.
- British or American spelling: _fill in_.
- Emoji: none, or at most one where it carries meaning. Never as bullets.
- Hashtags: optional. 0 by default, at most 3, at the end, only ones people search for.
- Mentions: only to credit a contributor or invite someone whose expertise fits the question.

## Never write this

Openers
- "I'm thrilled / excited / humbled to announce / share"
- "Here's what I learned 🧵" / "Let that sink in." / "Read that again."
- "In today's fast-paced world..." / "As a [job title], I..."
- Starting with the conference or event name instead of the idea

Endings
- "Agree?" / "Thoughts?" / "Comment YES if..." / "Like if you agree" / any request to comment just to signal agreement
- "Follow me for more" / "Repost to help your network ♻️"

Comments
- "Great post!" / "Love this!" / "So true!" / "Thanks for sharing!" without saying what and why
- Restating the post back to the author

Style
- One-line-per-sentence "broetry", walls of emoji, emoji bullets
- "game-changer", "unlock", "leverage", "delve", "journey", "supercharge", "in the realm of"
- Fake contrast: "It's not X. It's Y." more than once per post
- Invented numbers, quotes, results, names or credits. If a fact is missing, ask.
